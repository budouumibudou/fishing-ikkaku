4. GitHub の Actions で Pages の更新が成功してから、下のURLを開く。

【今回入れたもの】
・必須の海ぶどう（山の葡萄とは別の釣果）。練習3投の次に必ず出ます。
・アジを売る／生き餌用に残す。生きアジ1匹を使ってアオリイカを狙えます。
・サンダル、ボールペン、数量を選ぶ0G処分。
・売却／保管の1個・全部・数指定。指定数と受取額を連動。
・家の保管箱。黒鯛との交渉が失敗しても家の保管品は残ります。
・黒鯛との普通の会話失敗：携帯釣果は残り、竿を一段階戻す。
  なじんだ竿 → 扱いやすい竿 → 初心者の竿。
  初心者の竿が折れても、おじさんの予備で釣りを続けられます。
  竿の再購入は買取箱の「買う」から（120G／280G）。
・初めての黒鯛会話は失敗しても無傷。
・竿折れ累計10本で「黒鯛をシバいて追い返す」を習得。
  この反撃では竿も釣果も失いません。通常の黒鯛だけが対象です。
・強気の交渉だけ、事前に警告したうえで50%の携帯釣果＋生き餌全損。
  所持金・家の保管品は残ります。「話さずリリース」も選べます。
・魚ごとの成功帯と中央クリティカル幅。センタービタ賞は5G。
・船の受付は未解禁時にも理由を表示。6投＋おじさんとの交流、または街突破で無料同乗。
  同乗には金塊・免許・自船は不要です。
・既存の港の3人とのパンチアクションを維持。
・船・沖の魚・救命胴衣姿・波止場背景を差し替え。
・金塊の余計な口／黒鯛の欠けた口を直した画像を同梱。
・テスト用の自動保存、バックアップコード／JSON書き出しと復元。
  公開版の保存キーとは分離し、壊れたセーブは自動上書きしません。
  公開版のセーブは「復元」画面からテスト用にコピーできます（公開版は変更しません）。

【すぐ試す方法】
開始 → 設定 →「動作確認用」から、次に釣れるものを選べます。
海ぶどう・アジ・アオリイカ・黒鯛・金塊・サンダル・ボールペン・クエを選べます。
「竿折れを9回にする」→ 次の黒鯛で間違った返答 → 10本。
その次も黒鯛を選び、「シバいて追い返す」を確認してください。
このボタンは試遊を早めるため、テスト版だけに付けています。

【試遊で見てほしい点】
・魚／船／救命胴衣の絵と、スマホでの見え方。
・海ぶどうが4投目に出ること、アジの生き餌からイカを狙えること。
・3匹持っている時に1匹だけ売る／2匹だけ保管するなど、個数が合うこと。
・船の受付の返事と、出航／帰港ができること。
・竿の段階低下が重すぎないか、10本の反撃が面白いか。
・バックアップ → 再読み込み → 復元でテストの記録が戻ること。
