入れ方
1. ZIPを展開（すべて展開）します。
2. 中のファイルをすべて、GitHubの fishing-ikkaku のトップ階層へ Upload files でアップロードします。
   フォルダごとではなく、中のファイルを選んでください。
3. Commit changes を押し、反映後に以下を開きます。
https://budouumibudou.github.io/fishing-ikkaku/test-v06.html?update=062
4. 画面上部が v0.6.2 になっていることを確認してください。

本番のindex.htmlやmaintenance.jsonは含みません。
v0.6のテスト記録を引き継ぎます。セーブを削除する必要はありません。

今回の変更
・「港の裏通り・遊ぶ」からアクションを何度でも遊べます。
・横持ちでは「メニュー」→「港の裏通り・アクション」。
・「アクションで遊ぶ」は、船上からも開始できます。
・開始時の説明の後は、会話で戦闘が止まりません。
・勝敗で所持金・釣果・物語の進行は変わりません。
・終了後は開始前の釣り場に戻ります。×から途中で戻ることもできます。
・「もう一度」で続けて再挑戦できます。
・初回の物語は岸で「物語を進める：船長を探す」から遊べます。
・船の受付には直接行けます。
・投げている最中は、釣りが終わってからアクションを開始してください。
・v0.6.1の「ウキを見守る」で止まる不具合修正を含みます。

今回確認してほしいこと
1. 港の裏通りが、クリア後も開けるか。
2. 自由なアクションのテンポと、横持ちでの移動・パンチ。
3. 船上から遊び、終了後に船上の釣りを再開できるか。

この更新はアクションの再挑戦機能の追加です。
