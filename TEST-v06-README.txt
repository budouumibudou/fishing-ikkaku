■ 今回の変更
【縦持ち／横持ち】
・縦：海の下に大きな釣りボタンと通常のメニュー。
・スマホ横：海を左、釣り操作を右に置きます。
・横では会話・図鑑・売買・船を「メニュー」にまとめました。
・端末の回転で釣りの状態やセーブはリセットしません。
・横向きへの回転は強制しません。

【会話に気づく表示】
・波止場で新しい話があると、おじさんの頭上に吹き出し。
・画面に「おじさんから、新しい話」を表示。押すと話せます。
・釣り中は操作を遮らず、話は未読のまま残ります。
・会話を最後まで読まずに閉じた場合も、未読の通知が残ります。

【船上】
・主人公は救命胴衣を着て甲板の内側に立つ絵に変更。
・船長も船内に描き、船上の会話は船長が担当します。
・おじさんの話は帰港後まで残します。船上から通知を押すと帰港の受付へ。
・黒鯛で竿が折れた場合も、船上では船長が予備の竿を渡す台詞です。

【港の裏通り】
・金塊の噂が変に広まり、3人に絡まれる導入を追加。
・画面を切り替え、移動先と目的を表示します。
・ヤクザ、おばちゃん、警官それぞれの登場・撃退後に短い会話。
・噂の出どころ → 古い供え物 → 船長の受付、と手がかりがつながります。
・会話中は敵も操作も止まります。
・初回突破後は「港へ近道」から受付へ直行し、毎回の戦闘は不要。
・移動の長押しでコピー等が出ない処理を操作場面に追加。
・移動を押しながら、別の指でジャンプ／パンチができます。
・指を離す／操作が中断される／画面を回すと、移動を止めます。
・セーブコードはこれまで通り選択・コピーできます。

■ すぐ試す方法
開始後、歯車 →「動作確認用（テスト版限定）」を開きます。
・「船上の配置・会話を確認」：船へ移動。
・「港の場面をもう一度試す」：突破済みでも裏通りを試遊。
・「おじさんの新しい話を確認」：波止場へ戻り、新しい会話を発生。
  ※このボタンだけ、試遊のため友好段階を最初へ戻します。
前の海ぶどう・黒鯛・竿9本などの試遊ボタンも残しています。
大事なテスト記録がある場合は、試遊ボタンを使う前にバックアップしてください。

■ 確認した内容
JavaScriptの構文、HTMLの構造、画像・モジュールの参照。
ゲーム処理9グループ（竿折れ、売却、保管、バックアップ等）。
画面操作を模擬して、以下の流れを確認しました。
・吹き出し → 会話 → 未読を残して出航 → 船長と会話 → 帰港後も未読が残る
・横用メニューから船の受付を開く
・釣り中の回転で進行データが変わらない
・裏通りの導入 → 3人の戦闘／会話 → 受付 → 次回は戦闘を省略
・押下キャンセル／回転時の移動停止、長押しメニューの抑止イベント
・v0.5から引き継ぎ、公開版とv0.5を上書きしない

ブラウザ実行環境を用意できなかったため、実ブラウザの表示確認は未実施です。
特にiPhoneでの縦横レイアウト、長押し、2本指での操作は今回の試遊で確認してください。
