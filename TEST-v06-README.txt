入れ方

2. 中のファイルをすべて GitHub の fishing-ikkaku のトップ階層に Upload files で上書きします。
   フォルダごとでなく、中のファイルを選びます。
3. Commit changes を押し、反映後に以下を開きます。
https://budouumibudou.github.io/fishing-ikkaku/test-v06.html?update=063
4. 画面上部が v0.6.3 になっていることを確認します。

本番の index.html / maintenance.json は含みません。
v0.6 系テスト版の記録を引き継ぎます。削除せず「つづきから釣る」で進めてください。
初めて公開する時は、セーブのバックアップを取っておくと安心です。

今回の追加
・竿は4段階。最後の「大物用の竿」は650 G。上位ほど引き上げの緑の幅が広くなる。
・黒鯛に竿を折られると一段階下がる。買い直し価格はその段階の価格。
・船長の船には従来どおり無料で同乗でき、同乗だけでクエにもチヌ神にも到達できる。
・同乗して沖で5投 → 船長の免許講習（合格時1,000 G） → 自船「一獲丸」（2,500 G） → 船を改装（3,500 G）。すべて任意。
・クエは同乗なら沖の10投ごと、自船なら8投ごと、改装した自船なら6投ごとに確定。確定以外の投でも抽選される。
・船の購入・改装は帰港してから受付で行う。
・旧版で12,000 Gの自船を買ったセーブは自船ランクとして引き継ぐ。追加請求はしない。
・港の裏通りの繰り返しプレイと v0.6.1 の「ウキを見守る」停止修正も含む。

確認してほしいこと
1. 竿を買うたびに緑の成功帯が広がるか。
2. 船の購入・改装後、受付の表示と沖の表示が変わるか。
3. 進行途中のセーブで再開でき、釣果と所持金が残るか。

実機iPhoneでの操作確認はまだです。
