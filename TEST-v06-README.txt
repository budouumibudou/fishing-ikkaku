フィッシング テスト版 v0.6.4

入れ方
1. ZIPを「すべて展開」します。
2. 中のファイルをすべて GitHub の fishing-ikkaku のトップ階層に Upload files で上書きします。
   フォルダごとではなく、中のファイルを選んでください。
3. Commit changes を押し、反映後に以下を開きます。
https://budouumibudou.github.io/fishing-ikkaku/test-v06.html?update=064
4. 画面上部が v0.6.4 になっていることを確認します。

本番の index.html / maintenance.json は含みません。
v0.6 系テスト版の記録を引き継ぎます。セーブ削除は不要です。

今回の変更
・改装した一獲丸は沖の画面で外観が変化。白い大きな船室、紺と金の船体、充実した甲板装備。
・チヌ神にクエを返すと、夕暮れの港の画像と縦に流れるスタッフロールの「真のエンディング」へ。
・制作：葡萄🍇（budou）／ SPECIAL THANKS：Xのフォロワー様。
・金塊の初回売却で従来の短い冗談エンドを表示。真のエンディングとは別で、どちらもその後は釣りを続けられます。
・船長の船でクリアした時と改装船でクリアした時で、エンディング画像の船も変化。
・ロール中にページを閉じても続きからエンディングへ戻れます。「釣りを続ける」で港に戻り、記録を保存します。
・達成後は設定から真のエンディングを見直せます。
・「設定」→「動作確認用」→「真のエンディング演出を試す」で、未達成でもセーブを変えずに画像とロールだけ試せます。
・動きを減らす設定ではロールをスクロールして読めます。

継続する要素
・竿4段階、船の任意購入と改装、港の裏通りの再挑戦、海ぶどう、アジを使うアオリイカ、セーブのバックアップ。

実機iPhoneでの画面表示と操作確認はまだです。縦持ち・横持ちでロールの読みやすさを試してください。
