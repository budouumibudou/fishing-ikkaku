【新しい物語の順番】
1. 波止場で最初の妙な釣果を見せる。3投目までは練習、4投目に海ぶどう、5投目にボールペン。
2. 6投目でおじさんと釣り仲間に。9投目で船着場につながる潮の話を聞く。
3. 15投目で常連同士となり、金塊と沖の岩礁の噂を聞く。
4. 港の裏通りの騒動を一度だけ物語としてクリアし、船着場へ進む。
5. 船着場で釣る。遅くとも3投目に金塊が釣れる。船長に見せ、おじさんも呼ばれて一緒に船へ乗る。
6. 船釣りでアジなど本格的な魚を釣る。おじさんの新しい話は船上で読める。
7. クエを手元に残して船長に話し、岩礁の主の謎を聞いてからクエを返すと真のエンディング。記録を残して続けられる。

会話がある時は釣り場のポップアップと案内から開けます。裏通りの初回入口は「物語を進める」だけです。クリア後は自由再挑戦に変わり、導入と操作説明を繰り返しません。再挑戦の報酬はオキアミ、たまに賢者の餌です。賢者の餌で架空のレトロPC雑誌「袋とじの本」が釣れます。
ほかの釣り人・悠太と澄子は船着場の金塊を見せて出航できるようになった後、波止場に現れます。

【記録の引き継ぎ】
テスト版の保存キーを引き継ぎます。すでに旧テストで船釣りへ進んだ人は、その到達を維持します。旧版で裏通りまで進み船に乗っていなかった人は船着場の場面から進めます。本番版とは別記録です。新しい物語を最初から確認するには先にバックアップをコピーしてください。自動でセーブを消しません。
